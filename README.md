# Tens and Ones Games

Maths practice for a 6 year old: seeing numbers as tens and ones, and using that to add and subtract up to 100 without counting one by one.

Live: https://tens-and-ones-puppy.netlify.app

## Games

1. **High Five**: see five and some more (fingers, two-tone tower, ten frame)
2. **Pack Ten**: pack loose ones into tens, build a number from tens and ones
3. **Quick Look**: read a number from its tens and ones at a glance
4. **Friends of Ten**: pairs that make 10, then the gap to the next ten
5. **Jump in Tens**: add and subtract tens on a hundred square
6. **Fill the Ten**: add by filling up to the next ten first
7. **Break a Ten**: subtract, breaking a ten into ones when needed
8. **Mystery Box**: missing numbers with a whole and parts bar

Each game has three levels and six questions per round. There is no timer; a wrong answer gives a hint and another try.

## Technical

One self-contained `index.html` (HTML, CSS and JavaScript, no build step). Fonts load from Google Fonts. Progress is stored in the browser's localStorage.

To deploy, publish the folder as a static site (Netlify project `tens-and-ones-puppy`).
